# zi2zi-JiT 底模预训练

## 1. 预训练参数

| 参数 | 当前值 | 说明 |
|------|--------|------|
| 字体数量 | 400+ | 70% 简体中文、20% 繁体中文、10% 日文 |
| 字符数/字体 | 最多 800 | 最多使用 800 个字符 |
| Epochs | 2000 | 训练轮数 |
| 总图像数 | 300k+ | 约 30 万张训练图像 |

## 2. LoRA 微调当前配置

- 底模checkpoint: `models/zi2zi-JiT-L-16.pth`
- 模型: JiT-L/16
- LoRA 微调参数（可调整）:
  - `MAX_CHARS_PER_FONT`: 每款目标字体用于训练的字符数（当前默认 500，建议 800-1000）
  - `EPOCHS`: 训练轮数（当前 2000）
  - `LORA_R`: LoRA rank（默认 32，建议 64）
  - `LORA_ALPHA`: LoRA alpha（默认 32）
  - `EARLY_STOP_PATIENCE`: 早停耐心值（默认 100 epochs）
  - `EARLY_STOP_MIN_DELTA`: 早停最小改善（默认 0.0001）

## 3. Auto-Split 数据分配（重要！）

### 配置
```bash
--auto-split \
--train-ratio 0.8 \
```

### 工作原理
- **8:2 动态分配**：80% 训练，20% 测试
- **自适应任何字数**：
  - 200 字 → 训练 160，测试 40
  - 700 字 → 训练 560，测试 140
  - 9000 字 → 训练 7200，测试 1800

### 结论
无论目标字体包含多少字符（200-9000+），都会自动按 8:2 比例分配训练集和测试集。

## 4. 预训练数据规模计算

### 方案对比

| 方案 | 字体数 | 字符/字体 | 总图像数 | 预计时间(单卡) |
|------|--------|-----------|----------|---------------|
| 当前底模 | 400 | 800 | 300k | 数周(多GPU) |
| 方案A | 500 | 1000 | 500k | ~8-10天(RTX 5090) |
| 方案B | 500 | 2000 | 1M | ~2-3周(RTX 5090) |

### 计算公式

```
总图像数 = 字体数 × 字符数/字体
训练时间 ≈ (总图像数 / batch_size) × epochs × 单step时间
```

## 4. 何时考虑重新预训练

### 建议重新预训练的情况

1. **字符集差异大**
   - 目标字体使用罕见字符集（如古文字、方言字）
   - 现有底模未覆盖足够多的相似风格字符

2. **风格域差异大**
   - 目标字体风格极端（如极细、极粗、艺术字）
   - 现有底模的泛化能力不足

3. **数据量充足**
   - 有 400+ 款同类风格字体
   - 每款字体有足够多的字符（1000+）

### 不建议重新预训练的情况

1. **当前底模效果可接受**
   - 只是"还不够好"但基本可用
   - 提升幅度可能不大（10-20%）

2. **资源有限**
   - 单卡训练周期太长（>1周）
   - 中断风险高

3. **数据不足**
   - 相似风格字体 < 100 款
   - 单款字体字符 < 500

## 5. 更有效的替代方案

### 方案A: 优化 LoRA 微调

| 参数 | 当前值 | 建议值 | 预期提升 |
|------|--------|--------|----------|
| MAX_CHARS_PER_FONT | 500 | 800-1000 | 10-15% |
| EPOCHS | 1000 | 2000 | 5-10% |
| LORA_R | 32 | 64 | 5-10% |
| EARLY_STOP_PATIENCE | 100 | 150 | 防止过早停止 |

### 方案B: 数据增强

- 在 inference 时使用多样化的采样参数
- 后处理修正生僻字

### 方案C: 分阶段训练

1. 先用 500 字符训练基础 LoRA
2. 再用额外 300 字符进行细化

## 6. 决策流程图

```
开始
  ↓
当前效果是否可接受？
  ├─ 是 → 结束，当前配置足够
  └─ 否 → 继续
       ↓
  是否有 400+ 相似风格字体？
  ├─ 否 → 优化 LoRA 参数
  └─ 是 → 继续
       ↓
  是否有 2 周以上连续训练时间？
  ├─ 否 → 优化 LoRA 参数
  └─ 是 → 可以考虑重新预训练
       ↓
  确定要重新预训练？
  ├─ 是 → 准备数据，执行预训练
  └─ 否 → 优化 LoRA 参数
```
